# Symptom Search

Describe how you feel in plain English, and this ranks 975 medical conditions by how well their listed symptoms match. Each result shows which phrase matched which symptom.

This is a learning project. It compares text and can't diagnose anything, so please don't use it for medical decisions.

Code, benchmark and data sources: https://github.com/william5711/symptom-search

This Space is deployed from that repo by a GitHub Actions workflow, so changes should go there.
